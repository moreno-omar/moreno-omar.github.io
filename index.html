mcp-obsidian : Obsidian Retrieval over MCP

Rust • MCP Server • Published on crates.io

A read-only Model Context Protocol server that indexes a local Obsidian vault and answers from it deterministically: by tag, by full-text term, by wikilink-graph proximity, and by exact note. No embeddings and no model sit in the retrieval path, so the same vault plus the same query always returns the same result, and every hit cites the tag, term or link that matched it. Speaks stdio to desktop hosts and Streamable HTTP to remote ones, installs with cargo install mcp-obsidian, and ships as an MCPB bundle.
